この画面で実際に起きていること

1. 思考はトークンを生成しない

5つの役割 (Commander / Scout×2 / Worker×2) は同じ Qwen 0.5B の実フォワードで、 それぞれ異なる指示のもと最終隠れ状態 (1024次元ベクトル) を出します。 Chain-of-Thought のように「考えを文章で書き出す」ことはしません。 議論フェーズの生成トークン数は 0 です。

2. ベクトル通信 (仮想トークン注入)

各ラウンドの合意ベクトルは lm_head で語彙分布に共鳴させ、その期待埋め込みを 「仮想トークン」として次のフォワードの先頭に注入します。テキスト化を経ないので 量子化誤差以外の劣化なしに思考が伝わります。3Dシーンで中心へ伸びる線がこの注入です。

3. 摂動テスト (わざとズラす)

収束を検出すると、合意の対抗馬を混ぜた「偽の合意」を全役割に注入して耐性を試します。 それでも同じ答えに戻れば頑健、流されれば脆い合意として議論を続けます。 幻覚を「確信の脆さ」として機械的に検査する仕組みです。

4. 正直な比較

下部に同じ 0.5B 単独の直接回答を並べます。評議会は魔法ではありません — 同じ重みから、集約と摂動検査でどれだけ答えが安定するかを見るデモです。 失敗する質問もそのまま見えます。エンジンは自作の Rust 推論器 (JGEN形式 / mmap) です。
