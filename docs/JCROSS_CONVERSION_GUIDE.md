# Verantyx JCross 変換ガイド (知識と推論の分離)

本ドキュメントは、従来の Dense (密) な LLM パラメータから、Verantyx の根幹である「立体十字構造体（JCross）」形式への変換レシピを解説します。

## 💡 コンセプト：知識と推論の分離

Verantyx アーキテクチャでは、大規模言語モデルをテキスト生成器としてではなく、純粋な「思考エンジン」として利用します。そのためには、モデルが持つ巨大な重み（知識）の中から、推論のコアとなるトポロジー（U, S, V）を抽出し、言語生成に必要な余分な知識（ボトルネック）を意図的に切り離す必要があります。

このスクリプトは、SVD（特異値分解）を用いてモデルを以下の2種類の役割に合わせた `.jgen` 形式にコンパイルします。

### 1. Worker (ワーカー)
- **特徴**: Rank 256 の極限まで削ぎ落とされた重み。
- **目的**: 自然言語の出力能力を完全にパージし、「概念ベクトル」による無劣化のディスカッション（テレパシー通信）と永遠の記憶システムへの自動保存（Auto-Store）に特化させます。

### 2. Commander (コマンダー)
- **特徴**: Rank 1024 の高解像度な重み。
- **目的**: ワーカーたちの多角的な推論の総意（Latent Chain of Thought）を読み取り、必要に応じてユーザーへ自然言語として翻訳・デコードする役割を担います。言語文法を保持しています。

---

## 🚀 コマンド一つで変換するレシピ

リポジトリ内に用意された `jcross_build.py` を使用することで、誰でも簡単にHuggingFaceモデルから変換が行えます。

### 準備
必要なライブラリ（`torch`, `transformers`, `tqdm`）がインストールされていることを確認してください。

### ワーカー用重みの生成
```bash
python3 cli/scripts/jcross_build.py --role worker --model "google/gemma-4-12B" --output "gemma_12b_worker.jgen"
```
*※非常に軽量化された、純粋な思考ベクトル専用のバイナリが生成されます。*

### コマンダー用重みの生成
```bash
python3 cli/scripts/jcross_build.py --role commander --model "google/gemma-4-12B" --output "gemma_12b_commander.jgen"
```
*※自然言語への翻訳能力を維持した、高解像度のバイナリが生成されます。*

---

## 🛠️ その他のオプション

- `--model`: HuggingFace のモデルID、またはローカルに保存された Dense な PyTorch モデルのディレクトリパスを指定できます。
- **実行環境**: 12B クラスのモデルを SVD 分解するため、最低でも 24GB〜32GB 程度の RAM (Mac Unified Memory 等) が必要です。計算には数十分かかる場合があります。
