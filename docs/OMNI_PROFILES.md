# Omni 動作モード (Profiles)

`python3 verantyx.py` → **Omni** は、評議会・パズル・escalate を常時フル同時実行しない入口です。  
動作モードで「どの系統に振るか」を切り替えます。

**主張境界:** モード切替は**運用の構造**です。世界知識や正答率そのものを増やしません。精度の本体は**発話役 (speaker)** の選択です。合議は精度ブースターではありません — 詳細は [`benchmarks/README.md`](../benchmarks/README.md)。

組み合わせはハードブロックしません。相性の理論ガイドは `/guide` と本ドキュメントで確認し、最終判断はユーザーに委ねます。

## クイック設定と機能解説

| コマンド | 役割 |
|----------|------|
| `/settings` / `/setup` | クイック設定 (主UX · 1画面) |
| `?` / `/path` / `/delib` | 同上 (別名) |
| `/guide` / `/features` | 機能解説 (対話メニュー) |
| `/mode …` | 動作モードのショートカット |
| `/config` | 設定キーの表示・変更 (従来どおり) |

日常の切替は `/settings`。`/mode` 等はパワーユーザ向けショートカットです。

## 動作モード (概要)

| mode | 用途 (一言) |
|------|-------------|
| **`auto`** (既定) | 難易度に応じて既存モードへ振分するディスパッチャ |
| `fast` | 低遅延・短答 |
| `puzzle` | 整理・制約寄り (0.5B フォールバック経路) |
| `council` | ベクトル評議会 |
| `deep` | 品質優先 (大型話者がいるとき) |
| `hands` | 評議会のあと Agent で手足を動かす |
| `impl` | 実装特化 (検証・ツール予算寄り) |

設定キーの例: `deliberation.profile` (既定 `auto`)。CLI: `python verantyx_config.py show | set <key> <value>`。

## 主張境界 (再掲)

- **構造 ≠ 世界知識** — プロファイルは制御面。事実知識はモデルの話者に依存する。
- **合議 ≠ 精度ブースター** — 同一話者では評議会の正答率ゲインはほぼ無い ([ベンチ](../benchmarks/README.md))。
- Omni ≈ 大型単独モデル、とは**言わない**。精度は話者選択に依存する。
- 半コーデックや実験フラグを「万能」と主張しない。
